# Automata V9.0.0A1.0

Automata is a test candidate for X4: Foundations 9.0 with the Terran DLC. It adds YoRHa, a player-sponsored faction based at the Earth Bunker. YoRHa maintains +30 sponsor relations and mirrors the player's persistent diplomacy with other factions.

Use a disposable save for the first engine test. The extension ID is `nyto_automata`. Use only one extension that defines the `yorha` faction in that save. Operational planners start paused. YoRHa Operations appears in eligible player or YoRHa conversations. Founding and sector directives, expansion policy, and war authorization are available from that menu.

Open Operations Report to inspect the build, current directive, active operation, station projects and procurement blockers. Use the report to verify each stage before scaling up. Pausing prevents new planner decisions. Native builds and orders already issued can continue.

The verification record states the tests run and the remaining engine checks. This package has no installer. When authorized, extract the `Automata` folder into the X4 `extensions` directory.
