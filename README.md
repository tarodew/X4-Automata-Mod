# X4 Automata Mod

Automata is a mod for **X4: Foundations 9.0** that adds **YoRHa**, a player-sponsored faction built around Terran technology. YoRHa manages its own economy, stations, logistics and fleets while following the player's strategic direction.

**Development target:** `V9.0.0A1.0`, the first integrated gameplay test candidate. The September build log records bounded static validation through A0.4. A0.5 archives are available for recovery and still need a fresh source audit. In-game validation is pending.
